# Metamagic: Twinned Spell

When you cast a spell that targets only one creature and doesn't have a range of self, you can spend a number of sorcery points equal to the spell's level to target a second creature in range with the same spell (1 sorcery point if the spell is a cantrip).

 

Foundry Note: Once adding this to a sheet, you will need to tell it what resource to consume when used.

When casting Twinned Spell with a spell level higher than one, you will have to manually input the number of Sorcery Points consumed.
